# 📝 네이버 블로그 포스팅 매니저 & AI 사진 모자이크 스튜디오

네이버 블로그(Naver Blog) 운영자를 위한 **카테고리별 Markdown 원본 관리**, **AI 얼굴 자동 모자이크**, **네이버 스마트에디터 원클릭 복사**, **GitHub 영구 백업** 통합 웹 도구입니다.

---

## 🌟 핵심 기능

### 1. 📂 카테고리별 Markdown (.md) 원본 포스트 관리
- `posts/parenting/`: 육아 관련 마크다운 원본 글
- `posts/it/`: IT/테크 관련 마크다운 원본 글
- `posts/travel/`: 여행 관련 마크다운 원본 글
- 카테고리별 필터링, 새 글 작성, Markdown 실시간 수정 및 미리보기 지원.

### 2. 🐰 토끼 얼굴 모자이크 스튜디오 (AI 얼굴 모자이크 탭)
- **사진 + 영상** 둘 다 지원. 브라우저 내 AI(face-api.js)가 얼굴을 **자동 감지**해서 토끼
  스티커로 가리거나(기본), 기존처럼 픽셀 블러로 처리 — 둘 중 선택 가능.
- 영상은 프레임마다 얼굴 위치를 따라가며 토끼를 씌우고, **오디오 트랙 없이 저장돼 자동으로
  무음** 처리됨.
- 100% 브라우저 온디바이스(Client-side) 처리로 사진/영상이 어디에도 업로드되지 않음.
- 모바일 브라우저에서도 그대로 사용 가능 (반응형 레이아웃).
- 사진은 **여러 장 한 번에** 업로드해서 순서대로 자동 처리 (영상은 한 번에 하나씩 — 여러 개
  선택하면 큐에 담아 순서대로 처리). 자동 인식이 놓친 얼굴은 "얼굴 직접 추가"로 사진을 눌러서
  보완 가능, 잘못 눌렀으면 되돌리기 지원.
- 사진마다 **설명 메모**를 적어두면(뭐가 찍혔는지 한두 줄), Claude가 사진을 직접 보지 않고도
  그 메모만으로 포스트 글을 쓸 수 있어 토큰을 크게 아낀다. 메모는 채팅창에 붙여넣기용으로
  복사하거나, 아래 GitHub 업로드 기능을 쓰면 `captions.md`로 자동 저장됨.
- **GitHub에 설명 메모 바로 올리기**: 개인 액세스 토큰을 넣으면 설명 메모를 이 저장소의
  `public/images/<폴더>/captions.md`에 직접 커밋한다 — 채팅창에 붙여넣지 않아도 Claude가
  그 폴더를 바로 읽을 수 있음. **기본은 사진 자체는 올리지 않고 메모만 커밋** — 사진은 실제로
  블로그에 실리기 전에 직접 한 번 더 검토하고 원하는 방법으로 올리는 걸 전제로 함. "사진도
  같이 올리기" 체크박스를 켜면 처리된 사진까지 같이 커밋해서 다운로드→재업로드 단계를 아예
  건너뛸 수도 있음. 토큰은 브라우저 localStorage에만 저장되고 api.github.com으로 바로
  전송됨 — **이 저장소 하나에만 Contents 읽기/쓰기 권한을 준 fine-grained 토큰**을 만들어
  쓰길 권장(일반 `repo` 스코프 전체 토큰은 계정 전체에 쓰기 권한을 주므로 피할 것). 공용
  기기에서는 사용 후 토큰 입력란 옆 X 버튼으로 지우기.
- 처리된 사진/영상 **1-Click 다운로드** (개별 또는 전체 일괄).
- 같은 기능을 커맨드라인에서 폴더째 일괄 처리하고 싶다면 `automation/rabbit-mosaic/`
  (Python 스크립트)를 참고하세요.

### 3. 📋 네이버 스마트에디터 ONE 원클릭 변환기
- 마크다운으로 작성된 글을 네이버 스마트에디터 전용 서식(Maru Buri 폰트, 인용구, 본문 스타일, 표 등)으로 변환.

### 4. 🐙 GitHub 백업 및 버전 관리

## 🚀 시작하기 및 로컬 실행

### 패키지 설치 및 개발 서버 실행
```bash
npm install
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속하여 포스팅 헬퍼 및 모자이크 스튜디오를 바로 사용할 수 있습니다.

### 📱 휴대폰 등 다른 기기에서 접속하기 (같은 Wi-Fi 안에서)
GitHub Pages 배포를 기다릴 필요 없이, 컴퓨터에서 로컬 서버를 띄우고 **같은 Wi-Fi에 연결된
휴대폰 브라우저**로 바로 접속해서 쓸 수 있습니다.

```bash
npm run dev:lan
```
실행하면 터미널에 이렇게 두 줄이 뜹니다:
```
➜  Local:   http://localhost:5173/
➜  Network: http://192.168.x.x:5173/     ← 이 주소를 휴대폰 브라우저에 입력
```
`Network:` 뒤에 나오는 주소를 휴대폰(또는 같은 네트워크의 다른 기기) 브라우저에 그대로
입력하면 됩니다. 컴퓨터 방화벽이 막고 있다면 5173 포트를 허용해주세요. 컴퓨터에서 서버를
끄면(`Ctrl+C`) 휴대폰에서도 더 이상 접속되지 않습니다 — 외부에 공개로 노출되는 게 아니라
같은 사설 네트워크 안에서만 열리는 주소입니다.
