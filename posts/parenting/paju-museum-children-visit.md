# [아이와 가볼 만한 곳] 국립민속박물관 파주 어린이박물관 후기 (반짝반짝 폴짝콩짝 상설전시)

안녕하세요 대왕토끼입니다~ 🐰

할머니와 함께 국립민속박물관 파주 1층 **어린이박물관**의 상설전시 《반짝반짝 폴짝콩짝》을 다녀왔어요! 토끼인형이 박물관의 보물이 되어가는 이야기를 따라가며 유물 터치스크린부터 볼풀장, 낚시 체험까지 알차게 즐기고 왔어요 🐰

---

## 1. 반짝반짝 폴짝콩짝 기본 정보

| 항목 | 내용 |
| --- | --- |
| 전시 | 《반짝반짝 폴짝콩짝》 (국립민속박물관 파주 어린이박물관 상설전시) |
| 위치 | 경기도 파주시 탄현면 헤이리로 30, 국립민속박물관 파주 1층 어린이박물관 |
| 운영기간 | 2026년 5월 5일(화)~2028년 12월 31일(일) |
| 개관일 | 매주 화~일요일 (대체공휴일 개관) |
| 휴관일 | 매주 월요일, 1월 1일, 설·추석 당일, 대체공휴일 다음날 |
| 관람시간 | 10:10~17:10 (4회차, 회차당 70분) |
| 관람대상 | 출생연도 2019~2023년 어린이 (권장연령 6~7세) |
| 이용정원 | 회차별 60명(어린이·보호자 포함) |
| 이용요금 | 무료, 주차 가능 |

《반짝반짝 폴짝콩짝》은 어린이의 소중한 장난감인 토끼인형이 박물관에서 보물이 되어가는 이야기를 따라가며, 박물관의 기능과 소장품의 가치를 쉽고 즐겁게 탐구할 수 있도록 구성한 전시예요. 저희가 방문한 5월 30일은 마침 SAMG의 '위시캣' 매직카드 컬래버레이션(2026.5.5~2028.12.31, 공간 2배·재미 200% 확장)이 막 시작된 직후라, 요즘 방문하시면 위시캣 캐릭터 요소도 함께 만나보실 수 있을 거예요.

### 관람 안내

- 어린이 1명과 보호자 1명 동반 입장이 필수예요.
- 주말은 어린이 1명당 보호자 1명만, 평일은 어린이 1명당 보호자 2명까지 동반 입장할 수 있어요.
- 다자녀 가족은 보호자 1명당 어린이 5명까지 동반 입장 가능(현장에서 다둥이카드·가족관계증명서 등 증빙서류 확인 후 미예약 추가 인원 입장)해요.
- 사전예약: 국립민속박물관 파주 누리집 관람정보 > 예약하기
- 단체 관람·기관 견학은 사전 협의가 필요해요. (단체 문의 031-580-5895, 031-580-5879 / 기관 견학 031-580-5844, 031-580-5896)

### 예약·관람 유의사항

- 관람일 기준 30일 전 00:00부터 관람 전날까지 예약할 수 있어요.
- 입장 시간으로부터 20분이 지나면 사전 예약 티켓으로 입장할 수 없어요.
- 휴대폰 번호(ID) 하나당 1일 1회차만 예약 가능(선착순)해요.
- 현장접수는 당일 잔여분·취소분만큼만 가능해요.
- 대상 연령을 꼭 지켜야 하고, 주민등록등본·건강보험증·여권·가족관계증명서·키즈노트 등 증빙자료를 요청받을 수 있으니 미리 준비해두는 게 좋아요.
- 박물관 내에서는 음료·음식 섭취가 어려워요.
- 입장 QR코드는 입구 QR스캐너에 대면 돼요.
