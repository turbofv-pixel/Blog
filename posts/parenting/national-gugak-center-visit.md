# [아이와 가볼 만한 곳] 국립국악원 후기 (박물관 나와라 쿵딱·가야금·AR 춤 체험)

안녕하세요 대왕토끼입니다~ 🐰

서울 서초구에 있는 **국립국악원**에 다녀왔어요! 국악박물관의 체험교육 '박물관 나와라, 쿵딱!'에 참여해서 가야금 연주부터 북 치기, AR 춤 체험까지 우리 소리를 온몸으로 느끼고 왔어요 🥁

---

## 1. 국립국악원 기본 정보

국립국악원은 우리나라 전통음악과 무용을 전승·보급하는 국내 최고(最古)의 국악 전문 기관이에요. 국악박물관에서는 아이와 보호자가 함께 참여하는 체험교육을 상시 운영하고 있어요.

| 항목 | 내용 |
| --- | --- |
| 주소 | 서울특별시 서초구 남부순환로 2364 |
| 관람시간 | 10:00~18:00(17:30 입장 마감) |
| 휴관일 | 매주 월요일, 1월 1일 |
| 관람료 | 무료 |
| 문의처 | 02-580-3130 |

### 참여한 프로그램 - 박물관 나와라, 쿵딱!

전시해설과 사물놀이 연주가 함께하는 체험형 전시해설 프로그램이에요. 유아와 초등 프로그램이 시간대로 나뉘어 운영돼요.

| 항목 | 내용 |
| --- | --- |
| 운영 요일 | 매주 토요일 |
| 운영 시간 | 유아(5~7세) 13:00~14:00 / 초등(8세 이상) 15:00~16:00, 회차별 60분 |
| 신청 인원 | 1팀당 2인(보호자 1인 + 아동 1인) |
| 신청 시작 | 매달 첫 번째 화요일 오전 10시(공휴일이면 그 다음 평일 오픈) |
| 신청 사이트 | [e-국악아카데미 교육 신청](https://academy.gugak.go.kr/usrs/eduRegMgnt/selectOffEduCrsRegList.do) |
| 장소 | 국악박물관 상설전시실 |
| 문의처 | 국악연구실 박혜인 02-580-3152 |

- 보호자 동반 가족 프로그램이라, 연령이 맞지 않거나 보호자를 동반하지 않으면 참여가 제한될 수 있어요.
- 형제자매가 함께 신청하는 경우, 각자 다른 보호자 아이디로 따로 신청해야 해요.
- 프로그램 일정은 매달 새로 열리니, 방문 전 e-국악아카데미 공지사항에서 최신 일정을 확인하는 걸 추천드려요.
