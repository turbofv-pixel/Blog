# [아이와 가볼 만한 곳] 녹청자박물관 물레성형 체험 후기 (인천 서구 도자기 만들기)

안녕하세요 대왕토끼입니다~ 🐰

인천 서구 **녹청자박물관**에서 물레성형 체험을 하고 왔어요! 선생님이 1대1로 붙어서 도와주셔서 아이가 직접 물레를 돌려가며 도자기 그릇을 완성해봤답니다 🏺

---

## 1. 녹청자박물관 기본 정보

| 항목 | 내용 |
| --- | --- |
| 주소 | 인천광역시 서구 경서동 209-3(도요지로 54) |
| 관람시간 | 09:00~18:00 (관람 종료 30분 전까지 입장 가능) |
| 휴관일 | 매주 월요일, 공휴일 다음날, 1월 1일, 설·추석 연휴 |
| 관람료 | 무료 (체험 프로그램은 별도 유료) |
| 문의처 | 032-560-2932, 032-563-4341 |

### 물레성형 체험 프로그램

| 항목 | 내용 |
| --- | --- |
| 장소 | 일일체험실(2층) |
| 접수기간 | 매월 15일 09:00부터 (예: 9월 프로그램 접수 2026-08-15~09-18) |
| 대상 | 어린이, 청소년, 성인 |
| 개인 교육일 | 토·일·공휴일 (교육시간은 접수 페이지 참고) |
| 개인 접수 방법 | [온라인 접수](https://www.nokcheongja.or.kr/event/application.do) |
| 이용료 | 물레성형 개인 9,000원 / 흙가래성형 개인 8,000원 / 도자기페인팅 5,000원 |
| 단체 교육일 | 화~금 오전 10:00~(1시간 내외), 20인 이상 전화 사전예약 |

체험자 외 가족도 동반 입장할 수 있고, 접수 시 3명까지 함께 신청할 수 있어요. 온라인 접수는 매월 15일 오전 9시에 열리는데, 인기가 많아 생각보다 접수가 쉽지 않아요. 미리 로그인해두고 시간 맞춰 준비하시는 걸 추천드려요.

### 취소·환불 및 유의사항

- 체험예정일 3일 전 취소: 전액 환불
- 3일 이내(체험 당일 포함) 취소: 환불 불가
  - 예) 토요일 체험 → 수요일까지 취소 시 전액 환불
  - 예) 일요일 체험 → 목요일까지 취소 시 전액 환불
- 완성한 작품은 교육일로부터 6개월 내에 찾아가지 않으면 자동 폐기돼요.

## 2. 준비물 받고 신기해하는 아이

![도자기 만들기 준비물을 신기해하며 만져보는 아이](/images/nokcheongja-museum-pottery/rabbit_20260222_095516.jpg)

체험실에 도착해서 준비물을 받자마자 아이가 이것저것 만져보며 신기해했어요. 본격적인 체험 전부터 기대감이 가득했답니다.

---

## 3. 도자기 만드는 영상 미리 예습

<video controls src="/images/nokcheongja-museum-pottery/rabbit_20260222_101010.mp4"></video>

물레를 직접 돌리기 전에 도자기 만드는 과정을 담은 영상을 아이와 엄마가 함께 보며 예습했어요. 어떤 순서로 만들게 될지 미리 알고 나니 실전에 들어갈 때 훨씬 수월했어요.

---

## 4. 물레 위에서 시작된 첫 도전

<video controls src="/images/nokcheongja-museum-pottery/rabbit_20260222_100904.mp4"></video>

선생님이 아이마다 1명씩 배정돼서 물레 위에서 돌아가는 점토를 직접 손으로 만져가며 모양을 만들어 갔어요. 처음 만져보는 촉감에 아이도 조심스럽게 집중하는 모습이었어요.

---

## 5. 손바닥으로 크기 키우기 & 화장토 칠하기

<video controls src="/images/nokcheongja-museum-pottery/rabbit_20260222_100613.mp4"></video>

손바닥을 넣어 점점 그릇 크기로 만들어가고, 붓으로 화장토를 바르는 과정도 이어졌어요. 선생님과 함께 조심스럽게 색을 칠해보는 모습이 사뭇 진지했어요.

---

## 6. 가운데 손 넣어 오목한 부분 만들기

<video controls src="/images/nokcheongja-museum-pottery/rabbit_20260222_100727.mp4"></video>

가운데에 손을 넣어 실제 그릇의 오목한 부분을 만들어보는 순서였어요. 그 작은 손으로 조심스레 모양을 잡는 모습이 어찌나 귀엽던지요.

---

## 7. 마지막 마무리

<video controls src="/images/nokcheongja-museum-pottery/rabbit_20260222_100303.mp4"></video>

선생님이 친절하게 도와주시면서 마지막 마무리 단계까지 함께했어요. 아이도 나름대로 야무지게 마무리하려는 모습을 보여줬어요.

---

## 8. 완성! 그림과 글씨로 마무리

![완성된 그릇에 그림과 글씨를 쓰는 아이와 엄마](/images/nokcheongja-museum-pottery/rabbit_20260222_101211.jpg)

그릇을 다 빚은 뒤에는 표면에 그림과 글씨를 써서 최종 완성을 했어요.

![완성 직전, 그림과 글씨, 오늘 날짜를 적어 넣은 그릇](/images/nokcheongja-museum-pottery/rabbit_20260222_101208.jpg)

오늘 날짜까지 적어 넣으니 세상에 하나뿐인 작품이 완성됐어요. 완성한 작품은 6개월 안에 찾으러 가야 한다니, 잊지 말고 챙겨야겠어요.
