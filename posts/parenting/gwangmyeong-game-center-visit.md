# [아이와 가볼 만한 곳] 광명시 게임창작소 후기 (무료 VR·게임 체험, 콜라주 만들기)

안녕하세요 대왕토끼입니다~ 🐰

광명시 하안도서관 3층 **게임창작소**에 다녀왔어요! 자동차 레이싱 게임에 푹 빠졌던 1시간, 그리고 내려오는 길에 만난 콜라주 만들기 체험까지 무료로 알차게 즐기고 왔어요 🎮

---

## 1. 광명시 게임창작소 기본 정보

| 항목 | 내용 |
| --- | --- |
| 장소 | 광명시 게임창작소 (하안도서관 3층) |
| 주소 | 경기도 광명시 철망산로 46 |
| 개관 | 2020년, 전국 최초 게임 분야 메이커스페이스 |
| 휴관일 | 매주 금요일, 법정공휴일 |
| 이용료 | 무료 |
| 체험 콘텐츠 | VR에그(영화·게임 등 100여 종 콘텐츠), VR게임 체험기기, AR 인터랙티브 콘텐츠 체험기기, 스크린 스포츠 기기 등 |
| 예약 방법 | 네이버 예약 또는 [게임창작소 네이버 카페](https://cafe.naver.com/gamemakerspace)에서 사전 신청 |
| 문의처 | 02-2680-6992, 02-2680-6996~7 |

Cospaces(코스페이시스)를 활용한 카레이싱 게임 만들기 수업 같은 교육 프로그램도 별도로 운영돼요. 정확한 회차별 운영시간은 예약 페이지나 전화로 확인하고 방문하시는 걸 추천드려요.

<video controls src="/images/gwangmyeong-game-center/rabbit_20260726_102856.mp4"></video>

---

## 4. 1층 콜라주 만들기 체험

![다양한 모양의 가위로 콜라주를 만드는 아이](/images/gwangmyeong-game-center/rabbit_20260726_110258.jpg)

게임창작소 체험 시간이 생각보다 짧게 느껴져서 아쉬웠는데, 1층으로 내려오니 아이들이 간단히 체험할 수 있는 공간이 있었어요. 콜라주 만들기 코너였는데, 지그재그 가위·둥근 가위처럼 모양이 색다른 가위들이 신기했어요.

<video controls src="/images/gwangmyeong-game-center/rabbit_20260726_110334.mp4"></video>

아이가 직접 가위질과 풀칠을 하며 콜라주를 만드는 모습이에요. 유치원에 다니기 시작하면서부터 미술에 관심이 꽤 생긴 것 같아 지켜보는 저도 뿌듯했어요.
